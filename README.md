# Laboration 3 - Objektorienterad programmering med C#

## Beskrivning
Denna laboration är en konsolapplikation skapad i C#.
Programmet funkar som en gästbok där användaren kan
lägga till, ta bort och visa inlägg. 

## Funktioner
- Lägga till inlägg med namn och text.
- Ta bort inlägg genom att välja ett index.
- Visa alla inlägg.
- Spara och läsa in inlägg med JSON.

## Hur man kör programmet
1. Öppna projektet i Visual Studio eller en terminal.
2. Gå till projektmappen.
3. Kör kommandot `dotnet run`.

## Teknik
- C#
- .NET
- JSON-serialisering
